# aiimage

Local-first AI image and video creative studio for Windows.

This repository is being initialized from the supplied development plan. M1 is a foundation milestone, **not** a working GPU image generator. The React/Tauri shell and FastAPI service will be implemented and tested in subsequent commits.

Project name: **aiimage**. Optional ComfyUI integration and Krea-inspired canvas are planned for later milestones. M10 multi-character generation is **out of scope**.
